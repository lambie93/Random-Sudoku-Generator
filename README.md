It’s a web-based Sudoku generator that creates random Sudoku puzzles for users to solve. The grid updates each time you generate a new puzzle, and users can interact with the board by filling in numbers and checking their progress.

I made it because I enjoy logic puzzles and wanted to create something interactive and challenging that people can play anytime. It’s a fun way to combine problem-solving with coding.

I used HTML to create the Sudoku grid layout, CSS to style the board and make it visually clean, and JavaScript to generate random numbers and build valid Sudoku puzzles. JavaScript also handles user input and updates the grid dynamically.

I struggled with generating a valid Sudoku board because the numbers have to follow strict rules. I learned how to use logic and algorithms to ensure no duplicates appear in rows, columns, or boxes. I also improved my understanding of JavaScript, especially working with arrays, loops, and dynamic updates to the page.
